এই গাইডটিতে Cloudflare-এর বর্তমান অফিসিয়াল এবং আধুনিক স্ট্যান্ডার্ড—OpenNext 
(@opennextjs/cloudflare) ব্যবহার করে কীভাবে আপনার সম্পূর্ণ Next.js অ্যাপ্লিকেশনটি 
Cloudflare Workers-এ ডেপ্লয় করবেন, তা ধাপে ধাপে বর্ণনা করা হয়েছে।

--------------------------------------------------------------------------------
অধ্যায় ১: কেন এই আধুনিক OpenNext পদ্ধতি?
--------------------------------------------------------------------------------
১. কোনো স্ট্যাটিক এক্সপোর্ট ('out' ফোল্ডার) লাগবে না:
   পুরোনো পদ্ধতিতে 'output: export' করতে হতো, যার ফলে dynamic API Route 
   হ্যান্ডলারগুলো ফেইল করত। OpenNext-এ সম্পূর্ণ Next.js App Router (SSR, 
   Server Actions, app/api/db-check, app/api/items) সরাসরি একটি Cloudflare 
   Worker (.open-next/worker.js) হিসেবে রান করে।

২. নোড কম্প্যাটিবিলিটি (nodejs_compat):
   Cloudflare Workers V8 এজ রানটাইমে চলে। wrangler.jsonc ফাইলে 
   compatibility_flags: ["nodejs_compat"] থাকায় Cloudflare এর নিজস্ব 
   আউটবাউন্ড টিসিপি সকেটকে Node.js-এর 'net' ও 'tls' সকেটে রূপান্তর করে। 
   ফলে MongoDB ড্রাইভার নির্বিঘ্নে কানেক্ট হতে পারে।

অধ্যায় ৩: লোকাল ডেভেলপমেন্ট ও টেস্ট
--------------------------------------------------------------------------------
১. লোকাল Next.js ডেভেলপমেন্ট সার্ভার:
   npm run dev
   ব্রাউজারে http://localhost:3000 ওপেন করলে লাইভ MongoDB স্ট্যাটাস এবং CRUD দেখতে পাবেন।

২. OpenNext Workers বিল্ড যাচাই করা:
   npm run build:worker
   (এটি .open-next/worker.js বান্ডেল সফলভাবে তৈরি করবে)

৩. লোকাল Workers প্রিভিউ (Local Cloudflare Edge Isolate):
   npm run preview:worker
   (এটি Miniflare এজ রানটাইমে লোকালি চালিয়ে টেস্ট করবে)


--------------------------------------------------------------------------------
অধ্যায় ৪: Cloudflare Workers এ সরাসরি ডেপ্লয় করার নিয়ম (CLI Method)
--------------------------------------------------------------------------------
সবচেয়ে দ্রুত ও ঝামেলামুক্ত পদ্ধতি হলো Wrangler CLI দিয়ে সরাসরি ডেপ্লয় করা:

১. ক্লাউডফ্লেয়ারে লগইন করা (একবার করলেই হবে):
   npx wrangler login

২. সিক্রেট ভ্যারিয়েবল সেট করা:
   npx wrangler secret put MONGODB_URI
   (প্রম্পট আসলে উপরের বড় শার্ড URL-টি পেস্ট করে Enter দিন)

   npx wrangler secret put MONGODB_DB
   (প্রম্পট আসলে লিখুন: next_cloud_db)

৩. এক ক্লিকে বিল্ড এবং ডেপ্লয়:
   npm run deploy:worker

আপনার অ্যাপ্লিকেশনটি সেকেন্ডের মধ্যে Cloudflare Workers এর গ্লোবাল এজ নেটওয়ার্কে লাইভ হয়ে যাবে!


--------------------------------------------------------------------------------
অধ্যায় ৫: GitHub ও CI/CD ডেপ্লয়মেন্ট
--------------------------------------------------------------------------------
আপনি যদি গিটহাবে পুশ করে Cloudflare Dashboard থেকে ডেপ্লয় করতে চান:

১. কোড গিটহাবে পুশ করুন:
   git add .
   git commit -m "feat: migrate to OpenNext Cloudflare Workers architecture"
   git push origin main

২. Cloudflare Dashboard এ গিয়ে:
   - "Workers & Pages" -> "Create application"
   - আপনার রিপোজিটরি "me16376/next-cloud-mongodb" সিলেক্ট করুন
   - Build command: npx opennextjs-cloudflare build
   - Deploy command: npx wrangler deploy
   - Environment variables এ MONGODB_URI ও MONGODB_DB যোগ করুন।
